# 实验4：系统概要设计

## 实验目的

掌握架构设计与模块划分方法，基于实验2的需求和实验3的用例模型，完成系统分层架构、模块划分、模块依赖和接口定义。

## 项目选题

隐私计算数据共享平台（联邦学习 + 差分隐私）。

## 设计结果

- **总体架构**：表现层（Vue.js）、接口层（FastAPI）、业务逻辑层、数据访问层（SQLite）、联邦训练子系统（Flower + PyTorch + 差分隐私）
- **核心模块**：用户管理 UM、数据管理 DM、联邦训练 FT、隐私保护 PP、结果展示 RV、系统管理 AD
- **接口**：13 个 REST 接口、18 个模块内部接口、联邦训练通信接口
- **TBD 落实**：模型类型、差分隐私参数、日志保存周期、部署方式、聚合方式、参数存储

## 设计原则

1. 每个模块都可追溯到需求编号；
2. 上层只调用下层，禁止跨层反向依赖；
3. 模块之间只通过接口通信，不直接访问对方的数据库表；
4. 原始训练数据不出数据提供方本地；
5. 新增模型类型或参与方不影响已有任务数据和接口。
