# 隐私计算数据共享平台 需求规格说明书（SRS）

**版本**：V1.0  
**日期**：2026年9月20日  
**作者**：许博儒

---

## 1. 引言

### 1.1 编写目的
本文档描述"隐私计算数据共享平台"的功能需求和非功能需求，作为系统设计、开发和测试的依据。

### 1.2 项目背景
随着数据安全法规的实施，传统数据共享方式存在隐私泄露风险。本平台基于联邦学习和差分隐私技术，实现"数据可用不可见"的安全共享。

### 1.3 定义与缩写
| 缩写 | 全称 | 说明 |
|------|------|------|
| FL | Federated Learning | 联邦学习 |
| DP | Differential Privacy | 差分隐私 |
| PI | Privacy Budget | 隐私预算 |
| SRS | Software Requirements Specification | 软件需求规格说明书 |

---

## 2. 系统概述

### 2.1 系统目标
构建一个支持多方参与的隐私计算平台，允许数据提供方在不泄露原始数据的情况下，与数据使用方联合训练机器学习模型。

### 2.2 用户角色
| 角色 | 说明 | 权限 |
|------|------|------|
| 数据提供方 | 拥有本地数据，参与联邦训练 | 上传数据、参与训练、查看本机结果 |
| 数据使用方 | 发起训练任务，获取模型 | 创建任务、查看全局模型、查看训练结果 |
| 系统管理员 | 管理平台和用户 | 用户管理、任务管理、系统监控 |

### 2.3 系统边界
```
┌─────────────────────────────────────────────────────┐
│                   隐私计算平台                       │
├─────────────┬─────────────┬─────────────┬───────────┤
│  用户管理   │  数据管理   │  联邦训练   │ 隐私保护  │
├─────────────┴─────────────┴─────────────┴───────────┤
│                     服务端                          │
└─────────────────────────────────────────────────────┘
         ↑               ↑               ↑
    ┌────┴────┐    ┌────┴────┐    ┌────┴────┐
    │数据提供方│    │数据提供方│    │数据使用方│
    │ (本地)  │    │ (本地)  │    │         │
    └─────────┘    └─────────┘    └─────────┘
```

## 3. 功能需求

### 3.1 用户管理模块

#### 3.1.1 用户注册
- **需求ID**：FR-UM-001
- **描述**：用户可以注册账号
- **输入**：用户名、密码、邮箱、角色类型
- **处理**：验证信息完整性，密码加密存储
- **输出**：注册成功/失败提示

#### 3.1.2 用户登录
- **需求ID**：FR-UM-002
- **描述**：用户使用账号密码登录
- **输入**：用户名、密码
- **处理**：验证凭据，生成Token
- **输出**：登录成功返回Token，失败返回错误信息

#### 3.1.3 权限控制
- **需求ID**：FR-UM-003
- **描述**：不同角色访问不同功能
- **输入**：用户角色、请求资源
- **处理**：RBAC权限校验
- **输出**：允许/拒绝访问

### 3.2 数据管理模块

#### 3.2.1 数据上传
- **需求ID**：FR-DM-001
- **描述**：数据提供方上传本地数据集
- **输入**：CSV/JSON格式数据文件
- **处理**：格式校验、存储到本地数据库
- **输出**：上传成功确认

#### 3.2.2 数据脱敏
- **需求ID**：FR-DM-002
- **描述**：自动对敏感字段脱敏
- **输入**：原始数据、脱敏规则
- **处理**：应用脱敏规则（掩码、哈希等）
- **输出**：脱敏后数据

#### 3.2.3 数据格式校验
- **需求ID**：FR-DM-003
- **描述**：校验上传数据格式
- **输入**：数据文件
- **处理**：检查字段类型、完整性
- **输出**：校验结果（通过/不通过+错误原因）

### 3.3 联邦训练模块

#### 3.3.1 创建训练任务
- **需求ID**：FR-FT-001
- **描述**：数据使用方创建联邦训练任务
- **输入**：任务名称、模型类型、参与方列表、训练轮次
- **处理**：生成任务ID，广播给参与方
- **输出**：任务创建成功

#### 3.3.2 本地训练
- **需求ID**：FR-FT-002
- **描述**：数据提供方在本地训练模型
- **输入**：全局模型参数、本地数据
- **处理**：执行本地训练，生成梯度更新
- **输出**：本地模型更新

#### 3.3.3 参数聚合
- **需求ID**：FR-FT-003
- **描述**：服务端聚合各参与方模型参数
- **输入**：各参与方的模型更新
- **处理**：加权平均聚合
- **输出**：新的全局模型参数

#### 3.3.4 训练状态监控
- **需求ID**：FR-FT-004
- **描述**：查看训练进度和状态
- **输入**：任务ID
- **处理**：查询任务状态
- **输出**：当前轮次、参与方状态、损失值

### 3.4 隐私保护模块

#### 3.4.1 差分隐私注入
- **需求ID**：FR-PP-001
- **描述**：在模型更新中添加噪声
- **输入**：模型参数、隐私预算ε
- **处理**：拉普拉斯/高斯机制添加噪声
- **输出**：添加噪声后的参数

#### 3.4.2 隐私预算追踪
- **需求ID**：FR-PP-002
- **描述**：追踪每次查询消耗的隐私预算
- **输入**：查询操作
- **处理**：计算累计隐私消耗
- **输出**：剩余隐私预算

#### 3.4.3 安全参数传输
- **需求ID**：FR-PP-003
- **描述**：加密传输模型参数
- **输入**：原始参数
- **处理**：RSA/AES加密
- **输出**：加密后参数

### 3.5 结果展示模块

#### 3.5.1 训练曲线展示
- **需求ID**：FR-RV-001
- **描述**：可视化训练过程
- **输入**：训练日志
- **处理**：解析数据，生成图表
- **输出**：损失曲线、准确率曲线

#### 3.5.2 隐私消耗展示
- **需求ID**：FR-RV-002
- **描述**：展示隐私预算消耗情况
- **输入**：隐私日志
- **处理**：汇总统计
- **输出**：隐私消耗柱状图

## 4. 非功能需求

### 4.1 性能需求
| 需求ID | 描述 | 指标 |
|--------|------|------|
| NFR-PERF-001 | 系统响应时间 | < 2秒 |
| NFR-PERF-002 | 并发支持 | ≥ 10个参与方同时训练 |
| NFR-PERF-003 | 数据处理能力 | 支持100MB数据集 |

### 4.2 安全需求
| 需求ID | 描述 |
|--------|------|
| NFR-SEC-001 | 原始数据不出本地 |
| NFR-SEC-002 | 模型参数加密传输 |
| NFR-SEC-003 | 用户密码BCrypt加密存储 |
| NFR-SEC-004 | 接口鉴权（JWT Token） |
| NFR-SEC-005 | 满足ε-差分隐私保证 |

### 4.3 可靠性需求
| 需求ID | 描述 | 指标 |
|--------|------|------|
| NFR-REL-001 | 系统可用性 | 99.5% |
| NFR-REL-002 | 数据备份 | 每日自动备份 |
| NFR-REL-003 | 故障恢复 | < 30分钟 |

### 4.4 可维护性需求
| 需求ID | 描述 |
|--------|------|
| NFR-MAINT-001 | 模块化设计，低耦合 |
| NFR-MAINT-002 | 代码注释率 > 30% |
| NFR-MAINT-003 | 提供API文档 |

### 4.5 可扩展性需求
| 需求ID | 描述 |
|--------|------|
| NFR-SCAL-001 | 支持新增参与方 |
| NFR-SCAL-002 | 支持新增模型类型 |
| NFR-SCAL-003 | 支持水平扩展 |

## 5. 接口需求

### 5.1 用户接口
- Web端：Vue.js响应式界面
- 支持Chrome、Firefox浏览器

### 5.2 硬件接口
- 无特殊硬件要求

### 5.3 软件接口
| 接口 | 协议 | 说明 |
|------|------|------|
| 前端-后端 | HTTP/HTTPS | RESTful API |
| 参与方-服务端 | gRPC | 参数传输 |
| 数据库 | TCP | PostgreSQL连接 |

### 5.4 通信接口
| 接口 | 协议 | 说明 |
|------|------|------|
| 实时通信 | WebSocket | 训练状态推送 |
| 消息队列 | AMQP | RabbitMQ |

## 6. 数据需求

### 6.1 数据实体
| 实体 | 属性 |
|------|------|
| 用户 | ID、用户名、密码哈希、邮箱、角色、创建时间 |
| 数据集 | ID、名称、格式、大小、所有者、存储路径、创建时间 |
| 训练任务 | ID、名称、发起方、模型类型、轮次、状态、创建时间 |
| 模型参数 | ID、任务ID、轮次、参数数据、是否加密、创建时间 |
| 隐私日志 | ID、任务ID、查询类型、隐私消耗、时间戳 |

### 6.2 数据存储
- 用户数据：PostgreSQL
- 训练参数：文件系统 + Redis缓存
- 日志数据：SQLite

## 7. 约束条件

### 7.1 技术约束
- 开发语言：Python 3.9+
- 框架：Flask / FastAPI
- 联邦学习框架：Flower

### 7.2 法律约束
- 遵守《数据安全法》
- 遵守《个人信息保护法》

### 7.3 业务约束
- 原始数据必须保留在本地
- 隐私预算必须有上限
