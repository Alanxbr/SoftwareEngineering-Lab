# ISSUE-001 模拟训练实际样本数与数据集登记不一致

| 项目 | 内容 |
| --- | --- |
| 状态 | 已修复（`a12b575`） |
| 类型 | 功能缺陷 |
| 发现阶段 | 集成验证 |
| 影响范围 | 模拟模式联邦训练 |
| 优先级 | 高 |

## 复现步骤

1. 以数据提供方身份登记数据集，样本数填写 12000。
2. 以数据使用方身份创建任务，选择该数据集，运行模式为 `moni`。
3. 启动任务，等待完成后查看任务详情与轮次记录。

## 预期结果

每个参与方单轮训练应使用数据集登记的全部 12000 条样本；任务详情中的样本总数与数据集一致。

## 实际结果

`backend/federated/moni.py` 中写死了单轮样本上限：

```python
yangben = min(max(64, yangben_shu), 1024)
```

无论登记多少条，实际参与训练的样本最多 1024 条。任务详情显示 12000 条，但训练只用了 1024 条，指标与样本规模不符。

## 修复方案

改为可配置上限，默认 20000，允许通过 `PINGTAI_YANGBEN_SHANGXIAN` 调低：

```python
YANGBEN_SHANGXIAN = int(os.environ.get('PINGTAI_YANGBEN_SHANGXIAN', '20000'))
yangben = min(max(64, yangben_shu), YANGBEN_SHANGXIAN)
```

同时把演示数据集扩到 5200 至 15000 条，确保"千条样本起步"的演示场景真实参与训练。

## 回归验证

修复后 27000 条样本（15000 + 12000）、6 轮训练耗时 2.72 秒，曲线正常收敛；单元测试与集成测试全部通过。
