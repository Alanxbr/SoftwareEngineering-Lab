# ISSUE-002 系统日志按结束日期筛选漏掉当天记录

| 项目 | 内容 |
| --- | --- |
| 状态 | 已修复（`c656b1a`） |
| 类型 | 缺陷 |
| 发现阶段 | 单元测试 / 集成测试 |
| 影响范围 | 系统管理 - 系统日志 |
| 优先级 | 中 |

## 复现步骤

1. 以管理员登录，进入"系统日志"页面。
2. 结束日期选择当天，开始日期留空，点击查询。

也可以直接调用接口：

```bash
GET /guanli/rizhi?jieshu=2026-11-17
```

## 预期结果

返回当天产生的全部日志记录。

## 实际结果

返回 0 条。同一时刻把条件换成 `kaishi=2026-11-17` 可以查到 14 条，说明记录存在，是筛选条件把当天记录排除了。

## 原因分析

前端日期控件只传日期部分 `YYYY-MM-DD`，数据库中的 `rizhi_shijian` 为 `YYYY-MM-DD HH:MM:SS`。SQL 使用字符串比较：

```sql
z.rizhi_shijian <= '2026-11-17'
```

`'2026-11-17 19:13:00' <= '2026-11-17'` 结果为假，因此当天的所有记录都被排除。

## 修复方案

在 DAO 层按整天补齐日期边界，边界逻辑集中在一处：

```python
if len(kaishi) == 10:
    kaishi += ' 00:00:00'
if len(jieshu) == 10:
    jieshu += ' 23:59:59'
```
