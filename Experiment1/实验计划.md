## 一、课程设计选题：隐私计算数据共享平台

### 选题背景
随着《数据安全法》《个人信息保护法》实施，数据安全共享成为刚需。传统数据共享方式存在隐私泄露风险，隐私计算技术可在"数据可用不可见"的前提下实现安全共享。

### 核心技术
| 技术 | 说明 |
|------|------|
| **联邦学习** | 数据不出本地，模型参数加密聚合 |
| **多方安全计算(MPC)** | 多方联合计算，各方数据互不可见 |
| **差分隐私** | 在数据中添加噪声，防止个体信息泄露 |
| **可信执行环境(TEE)** | 硬件级安全隔离计算 |

### 功能模块
| 模块 | 功能描述 |
|------|----------|
| 数据管理 | 数据上传、脱敏、加密存储 |
| 联邦学习 | 模型训练、参数聚合、模型评估 |
| 隐私保护 | 差分隐私注入、MPC协议执行 |
| 任务调度 | 多方计算任务管理、状态监控 |
| 可视化 | 训练过程展示、隐私预算监控 |

### 选题优势
1. **专业契合**：网络安全+数据安全方向
2. **技术前沿**：联邦学习、MPC是当前热点
3. **冷门稀缺**：本科课程设计很少有人做
4. **实用性强**：可对接医疗、金融等真实场景
