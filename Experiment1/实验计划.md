## 一、课程设计选题：隐私计算数据共享平台

### 选题背景
《数据安全法》《个人信息保护法》实施后，数据安全共享成为刚需。隐私计算技术可在"数据可用不可见"前提下实现安全共享。

### 技术路线（简化版）
聚焦 **联邦学习 + 差分隐私**，不涉及复杂MPC协议：

| 技术 | 作用 | 复杂度 |
|------|------|--------|
| 联邦学习 | 数据不出本地，多方协作完成模型训练 | 中等 |
| 差分隐私 | 在模型更新里加噪声，防止个体信息被推断 | 较低 |
| 模型参数安全传输 | 通过HTTPS/TLS加密通道保护参数传输过程 | 较低 |

### 功能模块（精简版）
| 模块 | 功能描述 |
|------|----------|
| 用户管理 | 登录注册、角色权限（数据提供方/使用方） |
| 数据管理 | 本地数据导入、脱敏、格式校验 |
| 联邦训练 | 模型初始化、各参与方本地训练、服务端汇总参数、轮次管理 |
| 隐私保护 | 差分隐私噪声注入、隐私预算追踪 |
| 结果展示 | 训练曲线、准确率、隐私消耗可视化 |

### 选题优势
1. **专业契合**：网络安全+数据安全方向
2. **技术前沿**：联邦学习是当前热点
3. **冷门稀缺**：本科课程设计很少有人做
4. **难度可控**：使用现成框架，聚焦核心功能
