# 实验3：UML 建模

## 实验目的

掌握面向对象分析方法，学会使用 UML 建模工具，把实验2的需求规格说明书转换为用例模型，并对核心用例编写用例描述。

## 项目选题

隐私计算数据共享平台（联邦学习 + 差分隐私）。

## 建模工具

- PlantUML 1.2024.7（`.puml` 源文件，内置布局引擎）
- Graphviz 16.1.0（实验4绘制架构图时使用）
- 渲染命令：

```bash
java -jar plantuml.jar -charset UTF-8 -tpng xxx.puml
java -jar plantuml.jar -charset UTF-8 -tsvg xxx.puml
```

## 用例图说明

### 图 1：核心业务用例图

- 参与者：数据提供方、数据使用方、平台用户（抽象参与者）
- 用例：用户注册、用户登录、数据本地导入、数据脱敏、数据格式校验、创建训练任务、本地训练、参数聚合、训练状态监控、差分隐私处理、隐私预算追踪、模型参数安全传输、训练曲线展示、隐私消耗展示
- 关系：数据提供方和数据使用方泛化到平台用户；数据本地导入包含数据格式校验；数据脱敏扩展数据本地导入；本地训练包含差分隐私处理、隐私预算追踪和模型参数安全传输；创建训练任务包含参数聚合

### 图 2：平台管理用例图

- 参与者：系统管理员
- 用例：用户与任务管理、系统日志查看、角色权限控制、训练状态监控
- 关系：用户与任务管理包含角色权限控制和训练状态监控
