# 实验3：UML 建模

## 实验目的

掌握面向对象设计，学会使用 UML 建模软件，基于实验 2 的需求分析用用例图描述需求，并对核心模块编写用例描述。

## 实验内容

1. 下载并学会使用常用的 UML 建模软件；
2. 基于实验 2 的需求分析，用用例图描述需求；
3. 基于课程设计选定系统的核心模块，给出用例描述；
4. 绘制 2 个用例图（包含参与者、用例、关系）。

## 项目选题

隐私计算数据共享平台（联邦学习 + 差分隐私）

## 用例图说明

### 用例图 1：核心业务用例图

- **参与者**：数据提供方、数据使用方
- **用例**：注册登录、数据本地导入、数据格式校验、数据脱敏处理、本地模型训练、差分隐私加噪、模型参数加密上传、创建联邦训练任务、联邦聚合、查看训练结果、训练曲线展示
- **关系**：
  - 关联：数据提供方 → 注册登录 / 数据本地导入 / 本地模型训练 / 模型参数加密上传；数据使用方 → 注册登录 / 创建联邦训练任务 / 查看训练结果
  - 包含（include）：数据本地导入 → 数据格式校验、数据脱敏处理；本地模型训练 → 差分隐私加噪；创建联邦训练任务 → 联邦聚合
  - 扩展（extend）：训练曲线展示 → 查看训练结果

### 用例图 2：系统管理用例图

- **参与者**：系统管理员
- **用例**：管理员登录、用户管理、角色权限控制、训练任务管理、隐私预算追踪、系统日志查看、数据审计
- **关系**：
  - 关联：系统管理员 → 管理员登录 / 用户管理 / 训练任务管理 / 系统日志查看
  - 包含（include）：用户管理 → 角色权限控制；训练任务管理 → 隐私预算追踪
  - 扩展（extend）：数据审计 → 系统日志查看
